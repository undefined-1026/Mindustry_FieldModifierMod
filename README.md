# FieldModifier

Press "~" in-game to select the bullets, buildings, or units (I'm too lazy to add more) under the cursor to enter and view them, and modify their fields. If they are complex type member variables, a button will appear on the right to enter them
When you select a field, a small window will appear at the bottom for modification. There are two buttons in the top right corner: one to close and the other to open the JavaScript script dialog box. The value of the script expression will be used to assign the field (Note: This content is machine translated)
